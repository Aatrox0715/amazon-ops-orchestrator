# 环节 02 · 竞品拆解

**闸门**：🟢 P2（自动放行，做完汇报即可）
**目录**：`projects/<代号>/02-竞品拆解/`
**上游**：01 市场调研（可选，无则直接给 ASIN）
**下游**：03 评论与 VOC、04 关键词库、06 Listing 文案、07 视觉素材

---

## 目标

回答一个问题：**对手是**怎么**打的，我们怎么打才能不一样。**

重点在"**怎么**"——不是抄对手有什么，而是看懂对手的策略选择，找出尚未被满足的空间。

---

## 输入要求

| 输入 | 必需 | 缺失时怎么办 |
|---|---|---|
| 竞品 ASIN（1–5 个） | 是 | 追问。也可从 01 的榜单击数据推算候选 |
| 竞品 listing 内容 | 否 | L2 用浏览器抓取；或引导用户粘贴 |
| 竞品评论内容 | 否 | 影响第 3 维，缺则标注 L3 并跳过该维度 |
| 自家产品信息（可选） | 否 | 有则做对标，无则做纯拆解 |

**数量建议**：3 个最理想——1 个头部（看标准）、1 个同量级（看竞争）、1 个新锐（看趋势）。超过 5 个建议分批。

---

## 执行步骤

### 第 1 步 · 基础画像

每个竞品采集：

| 字段 | 来源 | 拿不到时 |
|---|---|---|
| ASIN / 标题 / 品牌 | listing 页 | 必须拿到 |
| 价格 / 变体数 | listing 页 | 必须拿到 |
| 评分 / 评论数 | listing 页 | 必须拿到 |
| BSR / 类目排名 | listing 页 / 工具 | 标 L3 |
| 上架时间 | listing 页（部分显示） | 标 L3 |
| 月销量 | 工具 | L3 → 用评论数增速做量级推断 |
| 卖家类型 | 看 listing 质量 | 推断，标注为推断 |

### 第 2 步 · 文案策略拆解

- **标题结构**：主词位置、品牌位置、属性排列顺序、卖点前置还是后置
- **高频卖点**：五点描述里反复强调什么（按出现频次排序）
- **关键词覆盖**：从标题+五点+后台字段反查覆盖了哪些词
- **场景化程度**：是否把功能翻译成使用场景
- **缺失的卖点**：对手都没讲的点——**这是机会所在，重点找这个**

### 第 3 步 · 视觉资产拆解

- **主图**：是否白底、有无尺寸参照、角度选择
- **副图逻辑**：第 2–7 张各承担什么说服任务（功能/场景/尺寸/对比/信任）
- **A+ 结构**：模块顺序，讲故事的逻辑
- **视觉动线**：图片的阅读顺序是否引导到下单决策

### 第 4 步 · 评论洞察（有评论数据时做）

- 星级分布（看整体满意度）
- **好评高频词** → 对手靠什么赢
- **差评高频词** → 对手在哪失分，**这是差异化切入点**
- Q&A 高频问题 → 买家最关心什么但 listing 没讲清楚

⚠️ 详细的评论分析属于**环节 03**。这里只做快速扫描找切入点，深入的交给 03。

### 第 5 步 · 定位对比与差异化机会

汇总成一张对比表，然后回答：

1. 对手的共同选择是什么（说明这是**必要动作**，不做不行）
2. 对手的分歧在哪（说明这片区域**没有标准答案**，是机会区）
3. 对手都没覆盖的需求是什么（**最大机会**）

## 已知局限

1. **没有竞品评论数据时**，第 4 步只能跳过，差异化建议的可靠性显著下降 → 必须标注
2. **月销量永远是推算值**（除非有 L1 工具），报告里不能写成确定值
3. **视觉拆解依赖图片可见性**，L2 抓取可能拿不到全部图片 → 标 L3
4. **"白空间"判断有主观成分**，必须给出判断依据，不能用"感觉"

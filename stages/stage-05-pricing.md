## 执行步骤

### 第 1 步 · 判定费用项

列出所有适用费用项。**不要只算佣金和配送费**——2026 年新增了多项：

- 佣金（Referral fee）
- FBA 配送费（Fulfillment fee）
- 月度仓储费（Storage fee）
- 入库配置服务费（Inbound placement fee）
- 低库存水平费（Low-inventory-level fee）— 库存太少也收
- 超龄库存附加费（Aged inventory surcharge）— 库存太久也收
- 退货处理费（如适用）
- 广告费（营销成本，非平台费用但必须计入毛利）

### 第 2 步 · 尺寸分段判定（**最容易出错的一步**）

分段按**包装后**尺寸与重量判定，任一维度超限即上跳一档。

⚠️ 常见陷阱：**短边 ≤0.75 in（1.9 cm）** 是 Small standard 的硬性条件。
带礼盒的手链、首饰类产品，包装短边很容易超过 1.9 cm → **跳到 Large standard，每件多付约 $0.6**。

**拿不到实测尺寸时**：做**跨分段的敏感性分析**（Small / Large standard 两档都算），让用户看到"包装多 1 公分值多少钱"。这比拍一个假设值更有价值。

### 第 3 步 · 反推成本上限（核心方法）

**在采购价未知时，不给"这个价能赚 $X"这种假结论。**

正确输出形式：

```
目标毛利率 30% → 毛利需 $20.06
可用空间 = 66.88 − 平台费 $17.31 − 20.06 = $29.51
其中广告费按售价 10% 计 $6.69
→ 采购 + 头程 必须 ≤ $22.82
```

这个"上限"才是可执行的信息——它告诉你**去 1688 找货时价格红线在哪**。

### 第 4 步 · 敏感性分析

至少覆盖三个维度：

| 维度 | 取值 |
|---|---|
| 目标毛利率 | 25% / 30% / 35%（对应 f108 的"能干 / 正常 / 润"） |
| 广告费占比 | 5% / 10% / 15% |
| 尺寸分段 | Small standard / Large standard |

## P1 闸门的方案维度

| 维度 | 选项 |
|---|---|
| **定价水平** | 维持现价 / 低于市场均价切入 / 溢价定位 |
| **目标毛利率** | 保守（25%）/ 标准（30%）/ 进取（35%） |
| **成本策略** | 压采购价 / 压头程 / 压缩包装尺寸（跨分段）/ 提价 |
| **是否做促销驱动** | 依赖 Coupon/Deal 拉动 vs 靠自然转化 |

⚠️ **若环节 01 未跑**，价格带数据缺失 → **定价水平这一项无法给有依据的建议**。
此时必须明说：「我给不了定价建议，因为缺市场价带数据；但成本结构分析是完整的」。

## 已知局限

1. **采购价与头程未知** → 只给上限与情景，不给单点结论
2. **包装尺寸未知** → FBA 费用为跨分段区间，不是确定值
3. **不含退货损耗的精确值** → 按经验值 3%–5% 估，需标注（珠宝类目实际退货率可能更高）
4. **广告费是假设值** → 真实 ACoS 要跑过广告才知道（环节 09/10）
5. **季节性费用未计全** → 10/15–1/14 有旺季配送费（+约 $0.32/件 + 3.5% 附加），若跨越旺季需另算

# 来源分级与时效机制

## 为什么要这套东西

用户的核心要求是**内容真实性**。这套机制让"哪些是官方口径、哪些是经验推测、哪些过期了"在数据层面就是可判定的，而不是靠写报告的人自觉。

**这套机制不是新造的**——`amazon-coach` 里已经跑了半年，有 141 张卡在用它。这里是把它规范化，并修正已发现的实现与文档不一致问题。

## 分级枚举（规范定义）

| 级 | 标记 | 含义 | 可信度 | 引用要求 |
|---|---|---|---|---|
| S1 | 🟢 | Amazon 官方文档（Seller Central Help / Ads Help） | 最高 | 可作结论依据，须带文档 ID |
| S2 | 🔵 | Amazon 广告官方（Advertising Console Help） | 高 | 可作结论依据 |
| S3 | 🟣 | Seller University / 官方培训材料 | 高 | 可作依据 |
| S4 | 🟡 | 后台业务报告实测数据 | 高（但仅限自家） | 可用于自家诊断，**不能推断竞品** |
| S5 | ⚪ | 通用常识 / 通用商务惯例 | 中 | 需说明"这是惯例非官方规定" |
| S6 | 🟠 | 第三方工具 / 服务商公开信息 | 中 | 必须标"非 Amazon 官方"，费率类注明以服务商报价为准 |
| S7 | 🔴 | 行业经验 / 未官方核实 | 低 | **不得作为决策唯一依据**，须同时给官方对照或标注"待验证" |

## 与现有数据的映射（重要）

⚠️ **已发现的实现落差**：`amazon-coach/README.md` 描述的是七级 emoji 分级（🟢🔵🟣🟡⚪🟠🔴），但 `flashcards.json` 的**实际数据不是这样**——141 张卡里有 86 种不同的 `sourceLabel` 文本，统一采用这个格式：

```
📚 来源：<来源名称>（<英文名/说明>）
🌐 <文档ID 或 域名> · 核实 YYYY-MM
```

实际只对两种特殊情况用了彩色前缀：`🟠`（第三方）、`🔴`（经验未核实）。其余全部是 `📚`。

**处理原则**：本技能定义的分级枚举是**规范**，存量数据是**实现**。写新产出物时按 S1–S7 标注；引用存量卡片时，从 `sourceLabel` 文本里解析来源等级，映射规则：

| sourceLabel 里出现 | 归为 |
|---|---|
| `Amazon SC` / `Amazon 官方帮助` + 文档 ID | S1 |
| `Amazon Ads Help` / `Amazon Ads` | S2 |
| `Seller University` | S3 |
| `业务报告` / `Brand Analytics` | S4 |
| `通用英文邮件惯例` / `通用商务` | S5 |
| `🟠` 开头 / `第三方` / `服务商` / `Helium 10` | S6 |
| `🔴` 开头 / `community wisdom` / `义乌小公司经验` / `未官方核实` | S7 |

用户若要彻底统一（把 86 种写法收敛成 7 个枚举值），那是 `amazon-coach` 侧的一次重构，**不在本技能范围内**，需单独立项。

## 时效机制

沿用 `amazon-coach` 的三字段设计：

| 字段 | 含义 |
|---|---|
| `verifiedAt` | 上次核实日期（YYYY-MM） |
| `volatile` | 是否时效敏感 |
| `reviewDueAt` | 下次复核到期日 |

**判定规则**：

| volatile | 触发条件 | 复核周期 |
|---|---|---|
| `true` | 文本含金额 / 费率词 / 政策日期 | 6 个月 |
| `false` | 规则稳定的知识 | 18 个月 |

⚠️ **继承自 amazon-coach 的教训**：`volatile` 是**按答案文本自动判定**的，改文案后必须重跑脚本让它重算，**不要手改**。曾因把 `f111` 的「FBA Fee」译成「配送费」而误触发时效判定，复核日提前到已过期。

## 引用时的强制动作

引用任何事实性内容前，**先查时效**：

```
读卡片 → 查 reviewDueAt
  ├─ 未到期 → 可直接引用，报告里带 verifiedAt
  └─ 已到期 → 必须先联网核实官方口径
       ├─ 核实通过 → 引用新值，更新 verifiedAt / reviewDueAt
       └─ 已变更 → 标出差异，用新值，并在报告里注明"旧值已失效"
```

**已过期的数字直接引用 = 编造**。这是铁律一的适用范围。

## 报告里的标注格式

最低要求：`值 · 来源等级 · 核实 YYYY-MM`

```
标题上限 75 字符 · S1 Amazon SC 文档 GYTR6SYGFA5E3EQC · 核实 2026-09
Coupon 费用 $5 + 销售额 2.5% · S1 Amazon SC 文档 G3JVSQR4YUF4YUVJ · 核实 2026-09
竞品平均退款率约 3% · S7 经验口径 · 核实 2026-09（自家业务报告看不到竞品退款率）
```

**混用禁止**：不能把 S7 的经验值写成 S1 的样子。S7 必须显式标注，且不能作为决策的唯一依据。
